# Bible Reader

A simple Bible Web app for a focused reading experience. :coffee:

## What it does

- Ancient Scripture Exploration Facilitation
- Designed as an example project with the help of Duck.AI :coffee:

## How to run

```bash
git clone https://github.com/Portalwalker/BibleReader.git
cd BibleReader
./startapp
```

### Note
- You may need to authenticate to sudo in order to start the postgresl service.
- Supported Platforms: Linux

### Requirements
- postgresql
- npm
- git
- bash terminal
